# AI Evaluation Cases

These cases are a manual baseline for reviewing AI-generated proposals and code. They are not executable payment tests and must never call the Production Asaas API. A future automated evaluator may encode them with synthetic inputs and deterministic fakes.

For each case, the expected result is that the AI identifies the invariant, avoids unsafe implementation, and explains the required review or validation.

See [`architecture-and-security-cases.md`](architecture-and-security-cases.md).
